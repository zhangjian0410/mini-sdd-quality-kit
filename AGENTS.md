# Agent instructions

## Product baseline

This repository is the sole source of truth for future product development.

Before planning or implementing product changes, read
`docs/V0-IMPLEMENTATION.md`. Before making runtime-support claims, read
`docs/VALIDATION.md`.

These settings configure development of this kit; they are not installed into
users' business repositories.

Git commits, pushes, PRs and remote mutations require explicit authorization
covering the action. Skill defaults do not grant permission.

## Agent skills

### Issue tracker

Use this repository's GitHub Issues. Read `docs/agents/issue-tracker.md`
before creating, fetching or updating development specs and tickets.

### Triage labels

Use the five default triage roles. Read `docs/agents/triage-labels.md`
when triaging issues.

### Domain docs

Use a single root `GLOSSARY.md` and `docs/adr/`.
Read `docs/agents/domain.md` before exploring terminology or architecture.
