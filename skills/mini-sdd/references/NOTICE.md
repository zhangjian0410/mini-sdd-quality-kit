# Method attribution

Changed adaptations of Matt Pocock `to-spec` (MIT) and GitHub Spec Kit `clarify`
(MIT). The pinned original content, commit/blob/license identities and adoption
record are indexed in the kit's `SOURCES.md`.

- Matt `to-spec` at `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d`:
  <https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/to-spec/SKILL.md>.
  Retains repository-informed synthesis, domain language and existing public
  verification seams. Removes issue publishing, triage updates, long exhaustive
  user-story output and framework setup requirements.
  [License](licenses/mattpocock-MIT.txt).
- GitHub Spec Kit `clarify` at `c43849408ac0de2ca6a52f14eaae71449776057b`:
  <https://github.com/github/spec-kit/blob/c43849408ac0de2ca6a52f14eaae71449776057b/templates/commands/clarify.md>.
  Retains ambiguity scanning, prioritizing consequential unanswered questions,
  integrating accepted answers and checking consistent testable requirements.
  Removes hooks, extension execution, prerequisite scripts, mandatory framework
  layout, fixed question quota, checklist machinery and planning handoffs.
  [License](licenses/spec-kit-MIT.txt).

The adaptation uses the kit's six-section Mini Spec, explicit consent and minimal
local records. It neither installs nor invokes either upstream framework.

- Superpowers `verification-before-completion` (MIT), source commit
  `22f0b463e7a5e579904dd6211a520321035526f7`:
  <https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/verification-before-completion/SKILL.md>.
  Retains checking actual commands/results before claims, separating inference
  from evidence and checking delegated work rather than trusting a success label.
  Adapts verification to AC/risk, including actual manual and static observations;
  removes mandatory full-command repetition for every message, automatic Git/PR
  side effects and any requirement to install or enable the upstream framework.
  [License](licenses/superpowers-MIT.txt).
