## Git inspection repair

filter driver names containing `=`. The former override encoding could allow
repository-configured clean/process filters to execute during Review Only
inspection, even when the helper reported success. The shared workspace and
fixed-comparison inspector now preserves complete keys with `--config-env`.

and protocol-valid process filters, execution markers, unchanged repository/Git
snapshots and raw content identities. The recorded final implementation run
discovered **81 tests: 67 passed, 14 opt-in live tests skipped**, exit 0.
Implementation `57489f3175a61a1c043a4c1802261975ca808f52` has the same tree as
merge `a9c0f986df93511c10d97ab2195670f4708ab905`. This preparation did not rerun
those tests or perform new full live host validation. A nonblocking suggestion
to reduce duplicated test assertions remains deferred.

## Source and use

The historical development source remains
`2f09ce38993548a5030d55b58603c84bd2a0d282`; this version includes the subsequent
G2 core/test repair and kit development documentation. Current core/test files
