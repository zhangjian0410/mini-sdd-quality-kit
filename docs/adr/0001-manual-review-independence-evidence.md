# Accept verifiable manual evidence of review independence

To support independent review across hosts, accept verifiable, manually supplied
evidence of a separate review context, reviewed input identity and read-only
controls, as well as evidence captured automatically by a host. Record the evidence
source explicitly. Automatic host capture is not a prerequisite, but an oral user
confirmation or reviewer self-declaration alone is insufficient: when independence
cannot be verified, retain the baseline's pending review outcome rather than
claiming `INDEPENDENT`.
